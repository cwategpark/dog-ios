- List: `GET /mobile/v1/assets?kind=tryon&pet_id=...&cursor=...&limit=...`.

- Accounts, pet profiles, private models, and order logistics retain the existing website contract. The canonical backend is the website repository; the historical backend copy in this repository is not the deployed service.
