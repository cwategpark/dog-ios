# Pawly iOS 首期前端

本轮业务代码在 Mac 开发。后端及契约修正通过 Mac DSH；SwiftUI 视觉与交互由主审直接在 Mac Public 工作副本编写，再由 DSH 集成回 dog-ios。未在 Windows 开发业务代码。

## 范围与入口
- 宠物：宠物切换、网站同源默认静态金毛、账户作品集及授权图片/GLB 预览。
- 附近：真实 MapKit 地图、前台一次定位或地图手选区域、发现开关、5/10/25 公里查询、联系申请。
- 消息：收到/发出的申请、接受/拒绝、联系人、幂等消息发送和重试、历史翻页、前台刷新、拉黑。
- 我的：已验证邮箱、稳定用户识别码、同步、黑名单管理、退出登录。
- 不提供商城、购物车或结账入口。图片和模型的生成仍在网站完成。

## 视觉与交互
沿用已有 PawlyTheme 的奶油白、橙色和鼠尾草绿。UI/UX 技能的两次设计系统检索均未得到适合现有 SwiftUI 宠物社交产品的匹配，因此使用原主题和通用原生可访问性规范作为明确回退，不持久化检索出的无关方案。
原生 SF 字体及 SF Symbols；主要触控区域至少 44pt；卡片 24pt 圆角；按钮 16pt；主要按钮改用深橙色 #B9431F，确保白色按钮文字对比度。适配系统深浅色、Dynamic Type 和安全区域；不自动旋转模型，不播放未存在的模型动画。

## 数据与身份
唯一认证源为 MobileAppStore -> MobileAPIClient -> KeychainTokenStore。页面不再使用旧 AppState/APIClient 登录。邮箱 OTP 走 /mobile/v1/auth/email/start 和 /verify；网站资产认领仍走独立 /v1/claims，iOS 登录不自动接管未认领游客数据。
展示 user_id 作为用户识别码，它不是登录凭据。所有私有图片通过 AssetService 授权获取字节，不使用无授权 AsyncImage；仅内存预览，退出时移除私有视图和会话。
空、加载、失败、会话过期、无宠物、无作品、无附近用户、待接受申请等状态有可见文案，不填造历史数据。

## 模型
默认资源为网站原始 website-golden-master.glb，46,036,096 字节，SHA-256 96efb8f20105d2280b332a13e926966c935c8e01e5ef5843be5183352283146b。
WKWebView 内使用本地固定 three.js 0.169.0 + GLTFLoader + OrbitControls，许可证随资源入包。仅加载 bundle 脚本和原生授权下载/校验后的 GLB 字节；不把 token 交给 JS，不运行时依赖 CDN。模型为静态形象，仅手势旋转/缩放。
不通过改扩展名伪造 USDZ。个人模型仅当实际格式为 GLB 才能预览，不支持格式明确提示。

## 地图与位置
当前 Google Maps SDK/key 尚未具备，本期先使用免 key 的真实 Apple MapKit，未把能力状态误记为 Google 接入完成。
后台只保存 0.05 度网格；地图圆圈代表粗区域，不是宠友实际位置。手选区域明确由用户确认；未选择前不会上报默认城市。发现默认关闭，不请求后台定位。

## 验收边界
Xcode 编译、真实 HTTP 契约测试、模拟器 UI 流程及截图分开记录，不能用其中一种替代其他验收。隔离 fixture 的测试宠物、联系人和图片仅用于 QA，不是生产历史。生产 SMTP、Google Maps、PostgreSQL/容器运行和真机签名须以实际环境完成后另行验收。
